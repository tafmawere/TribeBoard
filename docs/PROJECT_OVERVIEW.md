# Tribeboard — Project Overview

> **Superseded.** The canonical overview is `00_PROJECT_OVERVIEW.md`.
> This file is kept as a pointer so old links don't break.

Tribeboard is a family logistics coordination platform: households plan recurring
**Schedules** for children's routines, the app generates **Runs** (real-world trips
with stops), assigns **Drivers**, and family members track execution live.

- Product overview and status: `00_PROJECT_OVERVIEW.md`
- Core concepts and entities: `02_DOMAIN_MODELS.md`
- Users and roles: memberships are admin / parent / driver / observer (see `GUARDRAILS.md`)
